# 🔍 Decode Job and Company

嘿，最近正在找工作的你，有没有被一份比简历还长的岗位 JD 绕晕过？😵‍💫

满屏都是“负责产品规划”“推动项目落地”“具备行业洞察”，每个字都认识，看完依然说不清：

- 🏢 这家公司究竟卖什么？
- 💼 入职后每天要干什么？
- 🧭 岗位更偏产品、运营、售前，还是客户交付？
- 🧩 我的经历能不能对上？
- 🎤 面试时该重点讲哪个项目？

把岗位截图、招聘链接或整段 JD 交给这个 Skill，再说一句：

> 🔍 帮我解析这个 JD。

它会查询公司公开资料，拆解岗位的核心工作、能力要求、协作对象、交付结果和商业模式，帮你从招聘话术中找到公司真正想招的人。

如果当前工作区里还有你的简历，你也可以继续说：

> 📄 结合我的简历看看匹配度。  
> 🔗 帮我把已有经历对齐这个岗位。  
> 🎤 给我准备一套带着面试官走的话术。

Skill 会把 JD 要求与简历经历逐项连接，区分：

- ✅ 直接匹配
- 🔄 可迁移能力
- ⚠️ 真实能力缺口

并进一步生成：

- ✍️ 可以放进简历的能力表达
- 🗣️ 60—90 秒岗位定向自我介绍
- ⭐ 最值得主动讲的项目经历
- 🪝 能够引导面试官追问的事实钩子
- 💬 高频业务问题及候选人口吻回答
- 📋 面试前需要补充和核实的信息

所有结论都会尽量回到 JD、公司公开资料和你的真实经历，明确区分个人贡献、团队结果、合理推断与待验证内容。🛡️

🚀 让你从“这份 JD 到底在说什么”，走到“我该怎样用自己的经历拿下这场面试”。

## ✨ 核心能力

- 支持岗位文本、招聘链接、截图、图片和文档。
- 通过自然语言识别岗位解析与简历适配意图。
- 实时调研公司产品、用户、付费方和商业模式。
- 将岗位职责还原为实际工作动作与交付结果。
- 从当前工作区或附件中寻找用户简历。
- 按直接匹配、可迁移能力和真实缺口建立证据映射。
- 生成简历表达、自我介绍、追问路径和业务型面试回答。
- 区分已确认事实、合理推断和待验证事项。

## 🚀 使用方式

安装后，可以直接使用自然语言触发：

```text
帮我解析这个 JD
解释一下这个岗位
这个岗位平时干什么
分析一下这张招聘截图
```

结合简历时，可以这样说：

```text
结合工作区里的简历分析我的适配度
怎么把我的经历对齐这份 JD
帮我准备一套面试话术
根据我的优势设计几个面试追问钩子
```

## 📦 安装

克隆仓库：

```bash
git clone https://github.com/guge484384905-cpu/decode-job-and-company.git
```

将 Skill 目录复制到个人 Skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R decode-job-and-company/.agents/skills/decode-job-and-company ~/.codex/skills/
```

也可以保留仓库中的 `.agents/skills/decode-job-and-company` 结构，作为项目级 Skill 使用。

## 🛡️ 事实边界

- 公开资料不足时明确标记待验证事项。
- 社区和匿名信息只作为弱信号使用。
- 简历匹配以用户材料中的事实为准。
- 严格区分个人贡献、团队结果和个人方案。
- 禁止补造经历、职责、工具、指标和项目成果。
